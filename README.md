# مشروع الشاشة الذكية - كربلاء المقدسة 🕌

لوحة تحكم ذكية (Smart Dashboard) مخصصة للشاشات الكبيرة (مثل TCL 50 C65) تعرض أوقات الصلاة، الطقس المباشر، التاريخ الهجري والميلادي، وشريط إعلانات متحرك.

---

## 📁 محتويات المشروع:
- [index.html](file:///C:/Users/zfj_d/.gemini/antigravity/scratch/karbala-smart-screen/index.html): هيكل الصفحة والعناصر البصرية.
- [style.css](file:///C:/Users/zfj_d/.gemini/antigravity/scratch/karbala-smart-screen/style.css): التصميم المخصص للشاشات الكبيرة (Dark Mode بتدرجات مريحة للعين ومناسبة لتقنية QLED).
- [script.js](file:///C:/Users/zfj_d/.gemini/antigravity/scratch/karbala-smart-screen/script.js): الكود البرمجي الذي يتصل بالـ APIs ويقوم بالعد التنازلي وتحديث البيانات.

---

## ⚙️ الواجهات البرمجية المستخدمة (APIs):
1. **أوقات الصلاة:** واجهة [Aladhan API](https://aladhan.com/prayer-times-api) بإحداثيات مدينة كربلاء المقدسة، وطريقة الحساب الإثنا عشرية (معهد لواء قم).
2. **الطقس المباشر:** واجهة [Open-Meteo](https://open-meteo.com) المفتوحة والمجانية بالكامل (لا تتطلب أي مفتاح اشتراك).

---

## 🚀 كيفية تجربة المشروع على حاسوبك أولاً:
يمكنك فتح ملف `index.html` مباشرة بالنقر المزدوج عليه في أي متصفح (Chrome, Edge, Firefox).

---

## 📺 كيف تعرض الصفحة على شاشة TCL C65 (Google TV)؟

### الطريقة الأولى (الأسهل والأفضل - عبر الإنترنت):
1. ارفع مجلد المشروع على استضافة مجانية مثل **GitHub Pages** أو **Netlify Drop** (بسحب المجلد وإفلاته لتحصل على رابط مباشر مجاناً).
2. على شاشة التلفاز، افتح متجر Google Play وحمّل متصفح مخصص للتلفزيون مثل:
   - **BrowseHere**
   - أو **TV Bro**
3. افتح الرابط في المتصفح واضغط على زر **ملء الشاشة (Full Screen)**.

### الطريقة الثانية (عبر الشبكة المحلية داخل المنزل):
1. تأكد أن الحاسوب والشاشة متصلان بنفس شبكة الـ Wi-Fi.
2. شغّل خادم محلي على حاسوبك في نفس المجلد عبر بايثون:
   ```bash
   python -m http.server 8080
   ```
3. افتح المتصفح في شاشة التلفاز واكتب: `http://IP_COMPUTER:8080` (استبدل `IP_COMPUTER` بعنوان IP الخاص بحاسوبك).
